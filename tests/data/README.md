Small excerpts of the real source files, so the ingest parsers can be tested offline.

- `tahot_sample.txt`, `tipnr_sample.txt`, `tvtms_sample.txt`: STEPBible.org data (Tyndale House
  Cambridge), CC BY 4.0, https://github.com/STEPBible/STEPBible-Data. Excerpted, otherwise unchanged
  (the TIPNR `@Article` lines are omitted).
- `openbible_sample.jsonl`: OpenBible.info Bible Geocoding Data, CC BY 4.0, trimmed to the fields
  URIM reads.
